# v1 plan (approved 2026-11-25)

Status: approved 2026-11-25.

Scope is docs/design.md "v1 scope". Each step below is one `feature/*` PR to `main` with CHANGELOG, README and docs updated in the same PR. Per the delegation rules each code PR goes planner → builder → verifier; PR 3 (migrations) and PR 7 (secrets, deploy) are builder minimum.

## 1. Tooling and CI

- Next.js (App Router) + TypeScript app skeleton with pnpm, ESLint, Prettier (`{}`), Vitest, `tsc --noEmit`.
- `ci.yml`: `changes` job (skip heavy jobs on docs-only diffs), lint, typecheck, test, gitleaks; always-run `ci-ok` gate. `format.yml` on every PR.
- `dependabot.yml` for `github-actions` and `npm` (pnpm).
- After it merges: apply the `default-branch` ruleset (`ci-ok` + `format` required). Needs your approval.
- Done when: CI green on the PR, `pnpm dev` serves a blank Postcard shell.

## 2. Curated data and spoiler gating (test-first)

- zod schemas and loader in `lib/curated.ts` for `data/curated/missions.yaml`, `gates.yaml`, `items/*.yaml`; validation fails on any item without `visible_after_mission`.
- `lib/gates.ts`: `isVisible(item, currentMission)`, `nextGate(currentMission)`, `lockedSummary(gate, currentMission)`, `missionsInChapter(chapter)`, plus the optional-mission helpers `closesIn`, `countdownLabel`, `gateOptionals` and `safeToLeave`.
- Data: all 5 chapters and 91 main missions with order, plus optional missions (kind, opens_after, closes_at) that give derived checklist rows; Tourist Trap gate with what you lose; the first Tourist Trap items with sources (no Research flag since ADR 0008).
- Done when: gating tests cover before, at and after a gate, locked counts and the spoiler-safe picker list.

## 3. Database

- Drizzle schema: `progress` (current mission, spoiler mode), `item_checks`, `stat_levels`, `workouts`, `sources`, `candidates`. Drizzle migrations, better-sqlite3 client, WAL mode, `DATABASE_PATH`.
- Done when: migrations run from empty, integration tests round-trip progress and workouts on a temp DB.

## 4. Design system and components

- Tokens on `:root` for every palette role in light and dark (branding.md), Anton + Work Sans via `next/font`.
- Components named as in the design reference: PostcardHeader, ExitSign, StatStrip, StatRing, CategoryHeader, ChecklistRow, Chip, LockedRow, ProgressBar, PrimaryButton, plus the tab bar.
- Icon SVG and 180/192/512 PNGs, `app/manifest.ts`.
- Done when: a components page matches the design reference side by side in both themes at 375px.

## 5. Screens and flows

- Onboarding: chapter, then mission, both spoiler-safe; writes current mission.
- Home: PostcardHeader, ExitSign for the next gate, StatStrip, Up next (1-3 open items).
- Before you move on: categories with counts, ChecklistRows with Chips, LockedRow, item detail sheet (how-to, location, sources).
- Stats: card per character, StatRings, set level, Log a workout, last workout, slip tip.
- More: romance, criminal profile (research-first), story position picker, settings (theme, spoiler mode).
- Decide with the owner whether the checklist shows a gate's "what you lose" list before the gate is reached.
- Server actions for every write. Marking a gate mission done advances the current mission.
- Done when: all three flows in design.md work end to end on a phone viewport.

## 6. Scrapers

- `scrapers/` CLI (`pnpm scrape <source>`): robots.txt check, per-host rate limit, generic User-Agent, response cache, writes sources and candidates to the DB only.
- One or two first sources; candidates are never shown until promoted, and never rendered raw (ADR 0008).
- Discord webhook alert on failure or new candidates.
- Done when: a run against a live source stores candidates and a rerun is a polite no-op.

## 7. Deploy

- Dockerfile (standalone output, copying `data/curated`, `drizzle/` and `scripts/migrate.mjs` into the image; run `pnpm db:migrate` before the app starts), `compose.yaml` with the DB volume, `deploy.yml` that waits for CI, skips non-runtime paths and keeps `workflow_dispatch`.
- Cloudflare Tunnel route and Access app (Google SSO) for gta.dvdby.cc; origin ports closed. Weekly scraper timer on the box.
- Done when: a merge to `main` deploys, gta.dvdby.cc loads behind Access on the phone, and the PWA installs.

## Release

- Roll `## [Unreleased]` into `0.1.0`, tag, and set the idea page Notes.

## Risks to watch

- Launch-week data churn: best evidence with the safe tie-break, re-researched weekly (ADR 0008).
- Mission names past the current mission must never leak through the picker, titles or page metadata.
